## 비교 대상(Before) 캡처 — 임원 발표 Before/After 대비용

> DC Express 도입 **전** 실제로 쓰던 도구/파일을 캡처해, After(위 표) 화면과 **좌우 나란히** 배치하면 개선 효과가 한눈에 들어온다. 민감정보(서버명/IP)는 모자이크.

| ✅ | Before 대상 | 캡처 포인트 | 대비되는 After |
|----|-------------|-------------|----------------|
| ☐ | **Grafana 대시보드** | 흩어진 대시보드 여러 개(탭/URL 여러 개 띄운 상태) | 통합 대시보드 1화면 |
| ☐ | **자산관리 엑셀** | 장비 대장 엑셀 시트(행 많고 열 복잡한 상태) | 인프라 관리 목록 + 라이프사이클 |
| ☐ | **물리 배치도** | 기존 랙 배치 관리 방식(종이/파워포인트 도면/수기 메모) | Digital Twin 평면도 + 랙 열지도 |
| ☐ | **IPMI/BMC 개별 접속** | iDRAC/iLO 로그인 화면 또는 서버별 접속 목록 | 웹 원격 전원 제어 카드 |
| ☐ | **용량/보고 수기 파일** | 용량 산정·월간 보고를 만들던 엑셀/워드 | 용량 12개월 예측 + PDF 리포트 |
| ☐ | (선택) **알림 부재 증거** | 기존엔 사람이 대시보드를 봐야 알던 정황(별도 알림 도구 없음) | 알림 규칙 엔진 + 이력 |

> 캡처가 어려운 항목(예: "만료 관리 부재")은 화면 대신 **"기존: 없음 → 신규: D-day 자동 추적"** 문구 대비로 표현.

## 진행 방법
1. 위 표 순서대로 캡처 → 파일명은 `메뉴-내용.png` (예: `dashboard-overview.png`)
2. `docs/images/`에 모아두기 (이미 폴더 있음)
3. PPT/매뉴얼의 해당 섹션에 삽입
4. 다 끝나면 `final-report.md`의 "스크린샷 추후 삽입" 문구 제거

> 매뉴얼 **텍스트가 현재 UI와 다른 부분**이 있으면 알려주세요 — 캡처 전에 텍스트부터 맞춰드립니다.
