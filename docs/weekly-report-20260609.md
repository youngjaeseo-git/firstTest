### 1. 랙 배치 및 장비 관리 자동화

- **드래그앤드롭 랙 배치**: 랙 다이어그램에서 장비를 U 위치로 직접 끌어 배치
- **일괄 배치(Bulk Placement)**: 미배치 장비를 한 번에 여러 랙에 배치
- **검색 → 배치 연동**: 통합 검색 결과에서 바로 랙 배치로 이동
- **랙 열지도(Heatmap)**: 랙별 온도/사용률 시각화
- **배치 유효성 검증**: U 위치 충돌, 높이 초과 방지 로직 보강
- UX 개선: U Position 힌트, 랙 관리 컬럼 툴팁, 룸 정렬 순서 개선

### 2. 만기 관리 (ExpiryTracker) — 신규

- 인증서·라이선스·보증 만기일 추적 및 D-day 표시
- **인증서 자동 수집**: 서버에서 인증서 만료일 자동 감지
- **Cron 만기 점검**: 주기적 만기 임박 자동 알림 생성
- 대시보드 만료 임박 위젯 연동
- ExpiryTracker 테이블 부재 시에도 기존 기능 정상 동작하도록 방어 처리(try-catch)

### 3. 용량 예측 (Capacity Forecast) — 신규

- 장비 증가 추세 기반 성장 트렌드 차트 (과거 실적 + 12개월 전망)
- 리소스별(공간·전력·메모리·CPU) 월간 증가량 및 **소진 예측일** 산출
- 용량 소진 임박(6개월 이내) 경고 표시

### 4. 서버 사용 현황 추적 (Assignment) — 신규

- 서버별 사용자/용도 등록·반납 기능
- 사용 이력 기록 및 활성/이력 탭 분리 조회

### 5. Digital Twin 데이터센터 평면도 — 신규

- Lab-1/Lab-2/Lab-3 물리 배치를 반영한 SVG 평면도 추가
- 룸 클릭 시 랙 배치도로 이동
- (현장 피드백 반영: 평면도 레이아웃·디자인 가독성 개선, 타이틀 복원)

### 6. Prometheus 메트릭 장애 긴급 대응 ⚠️

- **증상**: 금요일 소스 반영 후 instance 필터가 적용된 전체 메트릭 차트가 동작하지 않음 (502 동반)
- **원인**: PromQL 정규식 이스케이프 처리 오류 — 문자열 리터럴에서 `\.`(잘못된 이스케이프)가 생성되어 Prometheus 400 유발
- **조치**: `escapeRe()` 이중 이스케이프(`\\.`)로 수정, 단위 테스트 동기화
- 재발 방지: 실제 차트 PromQL을 검증하는 `/api/metrics/health` 진단 엔드포인트 + 소스 정합성 점검 스크립트 추가

### 7. 운영 자동화 (Phase 4)

- DB 백업, 로그 로테이션, 장애 복구, 배포 파이프라인 스크립트 작성
- 마이그레이션 **멱등성(idempotent)** 처리로 `db push` ↔ `migrate deploy` 충돌 해소
