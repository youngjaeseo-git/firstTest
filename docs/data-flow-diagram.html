Alert System Data Flow

A
Alert Pipeline
1. AlertRule (DB) 에 PromQL + 임계값 + 심각도 저장
2. /api/cron/alert-check → 각 rule의 PromQL 실행
3. Prometheus 결과가 임계값 초과 시 → Alert 레코드 생성
4. MaintenanceWindow 체크 → 억제 기간이면 skip
5. NotificationChannel로 알림 발송 (Slack/Teams/Webhook/Email)
6. 미확인 시 EscalationPolicy에 따라 에스컬레이션
DB

ModelRole
AlertRule규칙 정의 (PromQL + 조건)
Alert발생한 알림 (FIRING/RESOLVED)
AlertAcknowledgement알림 확인 기록
MaintenanceWindow알림 억제 기간
NotificationChannel알림 채널 (Slack/Email/...)
