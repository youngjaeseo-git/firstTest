## 2. 서버 모니터링 (Server Monitoring)

| 기능 | 상태 | 설명 |
|------|------|------|
| 서버 목록 (리스트 뷰) | ✅ 완료 | 호스트명, IP, 상태, 위치, CPU, 메모리 표시 |
| 서버 검색 | ✅ 완료 | 호스트명/IP/모델 등으로 필터링 |
| CPU 사용률 차트 | ✅ 완료 | 실시간 라인차트 (15m/1h/6h/24h/7d 선택) |
| CPU Load (1m/5m/15m) | ✅ 완료 | 시간대별 CPU 사용 코어 수 |
| CPU Mode 분석 | ✅ 완료 | User / System 모드 비율 |
| CPU 코어 히트맵 | ✅ 완료 | 코어별 사용률 시각화 |
| 메모리 사용률 차트 | ✅ 완료 | 사용률 % + 절대값 (Used/Cache) |
| 디스크 I/O | ✅ 완료 | 읽기/쓰기 처리량, IOPS, 지연시간 |
| 디스크 사용률 | ✅ 완료 | 사용 % |
| 네트워크 대역폭 | ✅ 완료 | RX/TX 바이트/초 |
| 네트워크 에러/드롭 | ✅ 완료 | 수신/송신 에러 및 패킷 드롭 |
| TCP 연결 현황 | ✅ 완료 | Established / Close_wait 수 |
| 전력 소비 차트 | ✅ 완료 | Intel PCM 와트 단위 |
| 온도 모니터링 | ⚠️ 부분 | Prometheus job="temperature" 사용 (데이터 소스 한정) |
| 팬 속도 | ⚠️ 부분 | 별도 exporter 필요 |
| 서버 비교 뷰 | ✅ 완료 | 2대 이상 서버 메트릭 병렬 비교 |
| 시간 범위 선택 | ✅ 완료 | 15분 ~ 7일 범위 선택 가능 |

## 3. 인프라 관리 (Infrastructure Management)

| 기능 | 상태 | 설명 |
|------|------|------|
| 장비 목록 | ✅ 완료 | 전체 장비 테이블 (호스트명/IP/타입/상태/위치/CPU/메모리) |

| 장비 상세 메트릭 | ✅ 완료 | Prometheus 연동 서버의 실시간 차트 표시 |
| 상태 배지 | ✅ 완료 | 운영중/설치됨/수리중/퇴역/폐기 상태 표시 |
| CSV 대량 등록 | ✅ 완료 | CSV 업로드 → 미리보기 → 유효성 검증 → 일괄 등록 |
| 메모리 상세 페이지 | ✅ 완료 | DIMM 슬롯별 용량/타입/제조사/속도/채널 다이어그램 |

## 4. Prometheus Discovery (자동 탐지)

| 기능 | 상태 | 설명 |
|------|------|------|
| 타겟 동기화 | ✅ 완료 | Prometheus /api/v1/targets에서 서버 목록 가져오기 |

| 장비 등록 (Register) | ✅ 완료 | 타겟 → 장비 자동 생성 (CPU/메모리 자동 감지) |
| 장비 해제 (Unregister) | ✅ 완료 | 등록된 장비 삭제 및 타겟 연결 해제 |
| 동기화 통계 | ✅ 완료 | Total Synced / New / Updated 카운트 표시 |
