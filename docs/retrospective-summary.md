## 미로찾기와 AI

AI를 잘 쓰는 사람은 **"멈출 줄 아는 사람"**이다.

1. **같은 자리를 3번 맴돌면 멈춰라** — 같은 에러 반복 = 같은 막다른 길
2. **AI를 바꾸지 말고 질문을 바꿔라** — "에러 고쳐줘"(증상) → "성공 전제 조건은?"(구조)
3. **사람이 방향, AI가 실행** — "잘못된 길에 있다"는 메타 판단은 사람의 몫
4. **새 세션이 최고의 해결책일 때가 있다** — 긴 대화에서 AI도 맥락에 갇힌다
