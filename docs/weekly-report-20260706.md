### 1. 비용·생산성 비교 산출 (FP·맨먼스 기준)

- 기능점수(FP) 약 **700** 규모 산정 → 외주 시 **25~35 맨먼스·팀 3~4명·6~9개월·3.5~5.5억 원** vs 실제 **1인+AI 4.5개월·약 4,500만 원** → **비용 ~8~11배 절감, 인당 생산성 ~155 FP/MM(외주 대비 ~7~8배)**
- 역할별 업무분장(PL/백엔드/프론트/QA), 맨먼스↔인원↔기간 관계, 1인 외주 환산(~2.5~3년) 포함
- 상세 근거 문서(`cost-comparison-20260630.md`) 작성 후 **결과보고서 §7·회고 2종·PPT(경제성 슬라이드 신설)** 에 반영

### 3. 설계 허점 19건 발견 → 보안 5건 즉시 수정 ⚠️

- UML을 그리며 코드를 추적한 결과 **허점 19건(S1~S19)** 도출, 이 중 권한/보안 5건을 코드로 검증 후 즉시 수정:
  - **S1** 평가·워크로드 쓰기 API에 역할 검사 없음(VIEWER가 생성/삭제 가능) → `canEdit`/`canDelete` 가드 추가
  - **S2** 장비 할당 쓰기 역할 검사 없음 → 가드 추가
  - **S4** 메트릭 프록시 무제한 조회(DoS 여지) → 조회 창 7일 상한·쿼리 길이 상한 (팀A/B 토론으로 경량 하드닝 채택)
  - **S5** cron 시크릿이 URL로도 전달 가능(로그 노출) → Bearer 헤더 전용 + 상수시간 비교
  - **S17** 인증 응답의 공유 캐시 노출 → `Cache-Control: private`
- **S3**(알림 조직별 필터)는 DB 스키마 변경 필요 → v1.0 이월. 나머지 정합성 이슈(S6~S19)는 문서화 완료
- `npm run verify` 통과(62 테스트). ※ 문법/빌드 검증이며 **역할별 실동작(VIEWER 계정 차단 등)은 현장 확인 필요**
