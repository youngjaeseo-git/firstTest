## ⑤ 사용자 지원·요청 접수 — 🆕 전부 신규

현재 접수 채널 부재. 폐쇄망·1인 운영에 맞는 최소 비용안:

1. **앱 내 피드백 페이지** (v1.0 후보) — 요청/버그 폼 → DB 저장 → 설정 화면에서 조회. 폐쇄망이라 앱 자체가 접수처가 되는 것이 최적

3. **처리 원칙**: 버그는 등급별 목표 시간, 기능 요청은 월 1회 취합 → 백로그 반영
4. **사용법 안내**: 기존 산출물 재활용 — 매뉴얼 PPT 56슬라이드, `dcim_system_usage.md`, README
